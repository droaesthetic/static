# Playing Music

Static supports both **slash commands** and **prefix commands**.

## Slash Commands

**Example:**
`/play never gonna give you up`

## Prefix Commands

**Example:**
`;p never gonna give you up`

**You can also use direct links:**

**Example:**
`/play https://open.spotify.com/...`
`;p https://music.youtube.com/...`

Static will automatically recognize supported music platforms and begin playback.

# Automatic Chat Cleanup

Static is designed to keep your Discord channels clean.

## Slash Command Responses

**When using `/` commands:**
- Responses are private to the user
- Commands stay out of public chat
- Keeps channels organized

## Prefix Command Responses

**When using `;` commands:**
- Responses appear publicly
- Bot messages automatically delete after 30 seconds
- Static cleans up after itself

---

# Cleaning Commands

Static includes tools to help moderators maintain a clean music channel.

## Clean Command

**The clean command removes:**
- Bot messages
- Music commands
- Command responses

**It keeps:**
- The current Now Playing embed

This allows the Now Playing message to continue acting as a sticky message.

---

## Purge Command

**The purge command removes:**
- Bot messages
- Commands
- Old Now Playing embeds

**This is especially useful if:**
- A duplicate Now Playing message appears
- A message fails to auto-delete
- The channel needs a full cleanup

**Note:** 
These commands require the bot to have the **Manage Messages** permission enabled.
